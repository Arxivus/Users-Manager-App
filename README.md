👥 Users-Manager-App
Приложение для управления списком пользователей. Позволяет просматривать, добавлять и редактировать пользователей. Данные синхронизируются с MockAPI

🚀 Технологии

React (Vite)
TypeScript
MUI (Material UI) — компоненты интерфейса 
React Router DOM — маршрутизация
Axios — HTTP-запросы к API
MockAPI — фейковый REST API для хранения данных

📦 Установка и запуск

Клонируйте репозиторий:
git clone https://github.com/Arxivus/Users-Manager-App.git
cd UsersManager

Установите зависимости:
npm install

Запустите проект в режиме разработки:
npm run dev
Откройте http://localhost:5173 в браузере


🔌 API
Приложение использует MockAPI для хранения данных

Базовый URL:
https://6afc37b9892984c4494b2123.mockapi.io/api/v1/users

Доступные методы:

GET /users — получить список всех пользователей
GET /users/:id — получить пользователя по ID
POST /users — создать нового пользователя
PUT /users/:id — обновить данные пользователя

🧠 Как это работает

При загрузке приложения хук useUsers автоматически запрашивает список пользователей и сохраняет их в контекст
Главная страница (Main) отображает таблицу с пагинацией
При нажатии на "Редактировать" или "Добавить пользователя" открывается модальное окно с формой (UserEditForm)
При сохранении данные отправляются на сервер через axios, а затем обновляется локальное состояние
При клике на имя пользователя происходит переход на страницу /user/:id, где отображается подробная информация о нем
